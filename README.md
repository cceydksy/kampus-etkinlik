# Kampüs Etkinlikleri

Kampüsteki etkinlikleri listeleyen, detaylarını gösteren ve yeni etkinlik eklemeye yarayan web uygulaması.
Web Teknolojileri ve Programlama dersi dönem projesi.

## Sprint 1 · HTML ve Git

Yalnızca HTML ile kurulmuş beş sayfalık iskelet (CSS ve JavaScript yok).

| Sayfa | Açıklama |
| --- | --- |
| `index.html` | Uygulamanın amacı ve yaklaşan etkinlikler |
| `etkinlikler.html` | Etkinlik listesi ve ayın programı |
| `etkinlik-detay.html` | Bir etkinliğin afişi ve künyesi |
| `etkinlik-ekle.html` | Yeni etkinlik formu |
| `etkinlik-guncelle.html` | Doldurulmuş güncelleme formu |

**Canlı adres:** https://kampus-etkinlik-sigma.vercel.app/

**Etiket:** `sprint-01`
